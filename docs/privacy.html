Privacy Policy

Effective date: October 9, 2026 · Last updated: October 9, 2026

This Privacy Policy describes the Video Otomasyon Windows desktop workflow (the “Application”) and the public information website that links to it. The operator responsible for this Application is modmanclips (“Operator,” “we,” or “us”). Contact: emreutulu@gmail.com.

1. How the Application works

The Application runs on the operator's Windows computer. It helps select and render clips from a source video, with optional transcription, AI-assisted analysis, subtitles, dubbing, review through Telegram, and publishing integrations. The Operator does not operate a hosted user account system or central database for this desktop workflow. The person using the local Application decides which files and accounts to use and which information to send to an optional provider.

2. Information processed

  • Media and derived material: source videos and audio, extracted audio, transcripts, clip boundaries and summaries, rendered videos, subtitles, and dubbing files.
  • Preferences: clip identifiers, titles or summaries, timestamps, profile labels, and ratings used by the local preference feature.
  • Connected-platform information: OAuth access and refresh tokens, account identifiers returned by a platform, publishing options, captions, and post status. These are stored in the local project workspace.
  • Support correspondence: information you choose to include if you contact the Operator.

3. When information is sent to other services

Optional integrations send information only when the relevant workflow is used:

  • Google Gemini API: transcript text may be sent for clip selection, translation, or dubbing. Selected audio samples may be sent for audio-reaction analysis. Google processes these inputs under its applicable API terms and data policies; consult Gemini API Terms and Gemini API usage policies.
  • Telegram: if the review bot is enabled, selected video previews, rendered videos, and related approval messages are sent to the Telegram chat configured by the operator. Telegram processes them under its Privacy Policy.
  • TikTok: if connected, the Application uses the video.publish permission and requests creator publishing settings. After a separate user confirmation, it sends the selected video, caption, privacy choice, and other selected post settings to TikTok. TikTok processes this data under its Privacy Policy.
  • YouTube or Instagram: when the relevant optional integration is configured and used, the selected video and post information are sent to that platform under its own privacy terms.

The public website is a static information site. When hosted on GitHub Pages, GitHub may process technical request data as described in GitHub's Privacy Statement.

4. Purposes and legal basis

Information is processed to run the selected local editing and publishing workflow, keep its local preference feature, connect the platforms the operator chooses, and respond to support requests. Where applicable law requires a legal basis, the Operator relies on the user's direction to perform the requested workflow, consent for optional integrations, and legitimate interests in operating and securing the Application, subject to the user's rights under applicable law.

Because the Application processes media locally, the person or organization using it is responsible for deciding whether they have a lawful basis to process personal information appearing in that media and for meeting any notice or consent duties that apply to them.

5. Storage and retention

Media, transcripts, preferences, and OAuth token files are stored in the local project workspace and remain there until the operator deletes them or removes the relevant local files. The Operator does not receive a copy through a central Application server. Third-party services may retain information under their own terms and settings. Users should avoid submitting content they are not authorized to process and should review the relevant provider policies.

6. Security

Platform credentials are kept in local configuration files used by the Application. Anyone running the Application is responsible for protecting the computer, restricting access to its files, and revoking platform access when it is no longer needed. No storage system or internet transmission can be guaranteed to be completely secure.

7. Your choices and requests

You can choose whether to use optional AI and platform integrations, delete local files and token files, revoke third-party authorizations through the relevant platform, and stop using the Application. For privacy questions or requests concerning information the Operator controls, contact emreutulu@gmail.com. Requests involving information held by Google, Telegram, TikTok, YouTube, Instagram, or GitHub may also need to be sent directly to that provider.

8. Children

The Application is not designed for children to use independently. Do not use it to process a child's personal information unless you have the authority and legal basis required by applicable law.

9. Changes and contact

This policy may be updated when the Application or its data practices change. The current version and effective date will be posted on this page. Contact the Operator at emreutulu@gmail.com.

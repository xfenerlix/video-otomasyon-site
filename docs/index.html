Windows desktop workflow for video creators

Prepare, review, and publish short-form video clips from longer recordings.

Video Otomasyon is a local Windows workflow that helps a creator transcribe a source recording, identify moments for clips, render selected edits, and review them before publishing.

Read the Privacy Policy Read the Terms of Service

How the workflow works

1. Choose a source

The operator selects a local video file they own or are authorized to process.

2. Find candidate moments

The workflow transcribes speech and can use optional AI-assisted selection and audio analysis to identify clip candidates.

3. Render and review

Selected moments can be rendered in supported layouts, with optional subtitles or dubbing. A Telegram bot can send previews and videos for review.

4. Approve a destination

Publishing integrations are optional. A user reviews the rendered video and gives a separate, explicit confirmation before a platform upload.

Features and controls

  • Speech transcription and clip selection from a local source recording.
  • Optional portrait, split-screen, landscape, and compilation render formats.
  • Optional translated subtitles and English dubbing.
  • Telegram-based review and approval controls before platform publishing.
  • Optional YouTube, Instagram, and TikTok publishing integrations, configured by the operator.
  • Local preference records for selected and rated clips.

Where information goes

The desktop workflow stores source files, transcripts, rendered media, preference records, and platform credentials in the operator's local project workspace. It does not provide a hosted account or central application database.

  • Google Gemini: When optional AI features are used, selected audio and/or transcript text is sent to the Gemini API for clip selection, audio analysis, translation, or dubbing tasks.
  • Telegram: When the review bot is used, it sends selected previews or rendered videos and approval controls to the configured Telegram chat.
  • TikTok: The optional integration requests the video.publish permission, checks creator publishing settings, and sends the selected video and user-entered post settings only after the user confirms publishing.
  • YouTube and Instagram: If configured and selected, the workflow uses the applicable platform integration to upload content after the review step.

Each third-party provider processes information under its own terms and privacy practices. See the Privacy Policy for detail.

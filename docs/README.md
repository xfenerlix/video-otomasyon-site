# Public website draft

This folder contains a static, English-first website with Turkish legal pages for GitHub Pages. The home page explains the desktop workflow and shows direct Privacy Policy and Terms of Service links. The target public repository is `https://github.com/xfenerlix/video-otomasyon-site` (default branch: `main`).

## Before publishing

1. Verify that the operator (`modmanclips`) and public support mailbox (`emreutulu@gmail.com`) are correct and appropriate for public contact.
2. Confirm that the displayed product name matches the name used in the desktop app and TikTok Developer Portal. The draft uses `Video Otomasyon`, based on the project documentation.
3. Review the data-flow statements against the exact features enabled for review. Remove integrations that are not part of the submitted app and disclose any others that are.
4. Publish this folder from the public repository using **Settings → Pages → Deploy from a branch → main → /docs**.
5. Open the published home page and each legal page in a signed-out browser. For this repository, the expected URLs are `https://xfenerlix.github.io/video-otomasyon-site/`, `https://xfenerlix.github.io/video-otomasyon-site/privacy.html`, and `https://xfenerlix.github.io/video-otomasyon-site/terms.html`.
6. Enter the public home page, Privacy Policy, and Terms of Service URLs in the matching TikTok Developer Portal fields. Keep the policy links visible on the home page.

Do not submit these draft pages while any placeholder remains. Publishing policy pages does not itself guarantee app review approval; the app, its intended users, supported workflow, scopes, and review demo must also meet TikTok's requirements.
